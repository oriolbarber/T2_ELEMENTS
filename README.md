# Jocs del Tema 2 · MP06

Jocs per aprendre el vocabulari del **Tema 2. Elements constructius i espais d'una embarcació** del mòdul MP06 (1618) · Preparació d'embarcacions d'esbarjo per a treballs de manteniment · 1r CFGM MEF · Institut Els Tres Turons.

- `index.html` → versió per a **mòbil** (es pot instal·lar com a app i funciona sense connexió)
- `escriptori.html` → versió per a **ordinador o projector**

## Jocs

1. **Plànol**: posa cada nom al seu lloc dels dibuixos del tema.
2. **Qui soc?**: tria la paraula que correspon a la definició.
3. **Parelles**: uneix cada imatge amb el seu nom.
4. **Classifica**: envia cada paraula al seu grup.
5. **Via d'aigua**: endevina la paraula abans que s'enfonsi el bot.

Els punts (milles), les ratxes i les medalles es guarden al navegador de cada alumne.

## Multijugador

Botó **+ Jugadors** (a dalt a la dreta): partida per torns al mateix dispositiu.

- Es tria el nombre de jugadors (2–10), els noms, el temps total per jugador i el nombre de rondes.
- Cada ronda és un joc diferent (Plànol, Qui soc?, Parelles, Classifica, Via d'aigua…). El temps total es reparteix entre les rondes.
- Si un jugador acaba el repte abans d'hora, els segons que li sobren sumen milles segons el seu percentatge d'encerts.
- Guanya qui fa més milles; en cas d'empat, qui ha trigat menys. Al final surt el podi amb els 3 primers.
